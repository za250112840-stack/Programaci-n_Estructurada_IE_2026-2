# Ejercicio 10: Promedio ponderado para cálculo de calificación con ponderaciones

**Enunciado:** Diseña la lógica para un sistema de evaluación que reciba las notas de tres exámenes parciales, dos tareas y un proyecto final, y determine la calificación definitiva considerando que las evaluaciones tienen diferente porcentaje de peso sobre el promedio final.

*Investigación requerida:* El alumno debe proponer una distribución porcentual cuya suma dé el 100% (ej. Exámenes 50%, Proyecto 30%, Tareas 20%), calcular la nota mediante la suma de productos y validar el estado de aprobación mediante un condicional de corte (nota_final >= umbral_aprobatorio).
